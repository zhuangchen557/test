# 任意波形发生器上位机

基于 Python + PyQt6 开发的真实信号发生器风格上位机。**屏幕在左，物理按键区在右**，完全模拟真实信号发生器（Siglent SDG / Rigol DG 系列）的前面板布局和操作逻辑。

## 课题要求

1. 支持输出常用波形，支持幅度、频率等参数可设
2. 支持读取文件生成波形、支持手绘波形生成
3. 基于 Python 实现上位机界面、波形生成
4. 按规范设计 3D 打印、电路原理图、PCB

## 环境要求

| 依赖 | 说明 |
|------|------|
| Python 3.8+ | 推荐 3.10+ |
| PyQt6 | GUI 框架 |
| NumPy | 数值计算与波形生成 |

## 安装

```bash
pip install PyQt6 numpy
```

## 运行

```bash
python waveform_generator_gui.py
```

## 操作方式 — 与真实信号发生器一致

### 第一步：选择通道
按右侧 **CH1** 或 **CH2** 按钮，屏幕左下角显示当前活动通道。

### 第二步：选择波形
按右侧波形按钮之一：
| 按钮 | 波形 | 说明 |
|------|------|------|
| **Sine** | 正弦波 | 默认波形 |
| **Square** | 方波 | 可调占空比 |
| **Ramp** | 斜波/三角波 | 线性上升/下降 |
| **Pulse** | 脉冲波 | 窄脉冲 |
| **Noise** | 噪声 | 高斯白噪声 |
| **Arb** | 任意波 | 弹出文件选择对话框加载波形 |

> 按下波形按钮后，屏幕立即切换显示该波形。按钮高亮表示当前选中。

### 第三步：设置参数
**方法一：点击屏幕 + 数字键盘**
1. 在屏幕右侧的 **参数显示区** 点击要修改的参数（频率/幅度/偏置/相位）
2. 参数高亮，左侧软键显示 `> FREQ: _`
3. 在右侧数字键盘输入数值，如 `1` `0` `.` `5`
4. 按右侧 **单位键** 确认：
   - 频率参数：按 `kHz` / `MHz` / `Hz`
   - 幅度参数：按 `Vpp` / `Vrms` / `dBm`
   - 或按键盘 **OK** 键直接确认

**方法二：方向键微调**
1. 先点击屏幕参数选中
2. 按 `↑` `↓` 粗调（±10 步进）
3. 按 `←` `→` 细调（±1 步进）

### 第四步：开关输出
按右侧 **Output** 按钮切换输出开/关。按钮绿色 = 输出开启，灰色 = 输出关闭。

### 调制模式
1. 按 **Mod** 按钮 → 弹出调制设置对话框
2. 选择调制类型（AM / FM / PM / FSK / ASK）
3. 设置载波频率、调制频率、调制深度
4. 点击 OK → 屏幕显示调制波形
5. 再次按 **Mod** 关闭调制

### 扫描模式
1. 按 **Sweep** 按钮启用扫描
2. 使用方向键调整起止频率（当前版本使用默认扫描参数）

### 任意波加载
1. 按 **Arb** 按钮 → 弹出文件选择
2. 选择 CSV/TXT/DAT 文件（单列或双列数据）
3. 数据自动归一化并重采样到当前点数
4. 屏幕显示加载的波形

### 手绘波形
1. 按右侧 **✎ Draw** 按钮 → 打开手绘窗口
2. 按住鼠标左键在栅格上拖动绘制波形
3. 栅格带有 X 轴时间刻度 (ms) 和 Y 轴电压刻度 (V)，方便精确绘制
4. 按 **C** 键清除重画
5. 按 **Enter** 确认 → 波形自动应用到当前通道（Arb 模式）
6. 按 **Esc** 取消，关闭窗口

### Preset（恢复默认）
按 **Preset** 按钮恢复所有参数到出厂状态。

## 屏幕显示说明

| 区域 | 内容 |
|------|------|
| 栅格区 | 10×8 刻度波形预览，青色/黄色轨迹，左侧 CH1/CH2 箭头指示 |
| 右侧读数 | 大字体显示频率（蓝色）、幅度、偏置、相位 |

## 波形参数

| 参数 | 范围 | 单位 |
|------|------|------|
| Frequency | 0.000001 ~ 100000 | kHz |
| Amplitude | 0.001 ~ 20 | Vpp |
| Offset | -10 ~ +10 | V |
| Phase | -360 ~ +360 | 度 |
| Duty Cycle | 0.1 ~ 99.9 | %（方波/脉冲有效） |

## 导出

- **Save 按钮**：导出当前波形为 CSV 文件
- **WAV 按钮**：导出当前波形为 WAV 音频文件 (16-bit PCM)
